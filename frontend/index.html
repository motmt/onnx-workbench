QNN 骁龙 NPU 全 INT8 契约检查 未检查

按 AI辅助瞄准 逆向契约检查：输入 INT8 NHWC [1,H,W,3]、 输出 [1,C,N] 或 [1,N,C] anchor-free（C=4+类别数）、全 INT8、 不得内置 TopK / GatherElements / NMS。 合规 → 导出 NPU 专用 tflite；不合规 → 明确拒绝并列出原因。

NPU INT8 量化校准方式

说明：INT8 动态量化只量化权重，激活在运行时动态量化，体积约为 float32 的 1/4； INT8 静态量化需用所选校准数据确定激活范围，实际部署建议用真实数据集校准以获得最佳精度。 TFLite 导出依赖 onnx2tf 与 tensorflow，未安装时仅 ONNX 侧功能可用。
